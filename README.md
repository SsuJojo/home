# SsuJo_ Home

我的早期个人主页源码，也是一些前端视觉效果、个人链接与小实验的长期承载页面。

> **Website:** `me.zszs.uno`  
> **Status:** Legacy personal website / 持续保留的历史个人站

## 关于这个仓库

这个项目没有使用现代前端框架，而是直接用 HTML、CSS 和 JavaScript 编写。页面里保留了我早期做个人主页时对加载动画、滚动效果、响应式布局和视觉表达的尝试。

仓库目前包含：

- 个人主页 `index.html`
- 自定义样式与背景资源
- SVG 图形资源
- 若干历史页面 / 实验目录
- 早期移动端与专题页面
- GitHub Pages 自定义域名配置
- 与 Tapple 滚动动画实验的联动使用

## 技术特点

- 原生 HTML / CSS / JavaScript
- 无构建步骤，可直接静态部署
- 页面加载过渡与欢迎动画
- 自定义 SVG 与背景视觉
- 基于滚动位置的交互效果
- GitHub Pages / 任意静态服务器均可部署

## 本地查看

```bash
git clone https://github.com/SsuJojo/home.git
cd home
```

直接打开 `index.html` 即可查看主要页面。部分历史资源使用绝对路径或依赖旧目录结构，本地预览时可能与线上部署效果存在差异。

## 目录说明

这个仓库经历过多次个人主页迭代，因此目录中同时保留了现行页面和历史实验代码。它更像一份长期演化的个人网站档案，而不是一个从零整理过的模板项目。

## 项目状态

**可运行的历史个人站。**

我保留它主要是为了记录早期前端实践与个人主页演进。新的项目展示会逐步转移到更清晰的 GitHub Profile 与独立项目 README 中；这个仓库不再承担“解释我现在在做什么”的主要职责。
